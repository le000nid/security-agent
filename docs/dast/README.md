## Проверка поиска Juice Shop

Шаблон: `config/nuclei/juice-shop-sqlite-error.yaml`.

Отправляет поисковый запрос с одной кавычкой.
Находка появляется, если ответ имеет код HTTP 500
и содержит SQLITE_ERROR.

Это раскрытие внутренней ошибки базы данных.
SQL-инъекцию эта проверка сама по себе не подтверждает.

## Проверенный результат

Шаблон принят Nuclei и сработал на локальном Juice Shop.
Находка появилась в findings.json и общем report.md.
Общий DAST-запуск завершился с четырьмя находками, без LLM.

Контрольные запросы:
- apple: HTTP 200, три товара, без SQLITE_ERROR.
- apple'': HTTP 200, пустой список, без SQLITE_ERROR.

Проверка на HTTP 500 без SQLITE_ERROR пока не выполнена.
