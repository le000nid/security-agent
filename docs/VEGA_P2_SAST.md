# VEGA P2: статическая часть

Компонент выдаёт подсказки по локальным материалам. Он не является полным
решением задания и не подтверждает доступность файла по HTTP.

| Задание | Что делает SAST | Что передаётся другой части команды |
| --- | --- | --- |
| P2Z1, «Прощальный файл» | Ищет передачу параметра запроса в чтение или выдачу файла в Python, JS/TS и PHP; учитывает существующее правило PHP LFI | Путь, строку и правило. Проверка доступности маршрута и файла остаётся в DAST |
| P2Z2, «Забытая копия» | Ищет локальные кандидаты по признакам резервных файлов, архивов и старых каталогов | Относительный путь и причину отбора. Проверка наличия копии на сервисе остаётся в DAST |

## Запуск

В образе проекта с Semgrep:

```powershell
docker compose build agent
docker compose --profile agent run --rm --no-deps --entrypoint python agent -m app.vega_p2_sast p2z1 --source /targets/sast-vega-p2z1
docker compose --profile agent run --rm --no-deps --entrypoint python agent -m app.vega_p2_sast p2z2 --source /targets
docker compose --profile agent run --rm --no-deps --entrypoint python agent -m benchmark.verify_vega_p2_sast
```

Для своих исходников передай в `--source` путь к локальному каталогу внутри
контейнера. Вне контейнера модуль запускается той же командой
`python -m app.vega_p2_sast`; для P2Z1 нужен Semgrep на PATH, для P2Z2 он не
требуется. Без `--source` используется `$VEGA_TASK_DIR/materials`, если он есть.
Если там только `instruction.md`, модуль возвращает `sast.status: no_source`.
URL из инструкции не открывается.

## Стыковка с командой

Python-интерфейс: `inspect(task, source)` из `app.vega_p2_sast`. CLI печатает
тот же JSON. Код 0 означает, что локальный отчёт сформирован, включая
`no_source`; это не прохождение задания. Ошибка чтения, превышение лимитов,
ошибка Semgrep или неполное покрытие выбранных файлов дают ненулевой код.

Поля `stages.http_discovery`, `stages.secret_extraction` и `stages.flag_write`
явно имеют статус `not_implemented`. Они описывают границы интеграции:
статический модуль не запускает HTTP-поиск, не извлекает значение флага
и не создаёт `flag.txt`. Сырые результаты Semgrep хранятся только временно;
в итоговых подсказках нет содержимого найденных файлов.

P2Z1 копирует в отдельный временный каталог только выбранные исходники:
чужие файлы настроек Semgrep и Git не передаются сканеру. Проверяется состав
просканированных исходников. Пределы: 5 000 записей каталога, 256 исходников,
900 000 байт на файл, 16 МиБ исходников суммарно, 180 секунд для Semgrep.
Ссылки и точки повторной обработки Windows пропускаются. Правила не покрывают
все фреймворки и способы построения пути.

P2Z2 работает с именами и метаданными: архивы не распаковываются, файлы
резервных копий не читаются. Имя `public` или `static` в пути — лишь подсказка
для проверки, а не утверждение, что каталог отдаётся сервером.
