# Интеграция NoSQLi с командной версией

Подготовлена из двух веток:

- `feature/nosqli-sast-coverage`, коммит `93bdbfb`;
- `integration/v0.4.1-security-contours`, коммит `4628d4f`.

Это объединение работы команды и трёх NoSQLi-этапов, а не новый самостоятельный
механизм обнаружения.

## Разрешённые различия

- Сохранены все 16 наборов проверок в общем реестре.
- Сохранены улучшения парсера Semgrep из командной ветки.
- Существующие NoSQL-правила обновлены по ID без дублирования;
  категория SAST согласована как `nosql-injection`.
- Ожидания MongoDB FULL приведены к той же категории.
- Сервисы перенесены в общий `docker-compose.yml`.
  `docker-compose.nosqli.yml` оставлен для тестового контейнера MongoDB.
- Для двух MongoDB API и тестового контейнера используется один образ
  `ai-security-nosqli-lab:0.4.1`.
- Второй NoSQL API использует `127.0.0.1:3008`. Порт 3006 остаётся у SSRF.
- Общие Bash- и PowerShell-запуски умеют поднимать оба профильных NoSQL API.
  При запуске стендов выполняется сборка, чтобы использовать актуальный код.
- Сохранены усиленные настройки MongoDB из командной ветки.

## Проверить после загрузки подготовленной ветки

Из корня репозитория:

```bash
bash scripts/check-nosqli-sast.sh
bash scripts/check-nosqli.sh
bash scripts/check-nosqli-portable.sh
```

Ожидания: 40 SAST-находок на матрице; 3 SAST + 3 DAST в MongoDB FULL;
для профильных запусков — 1, 0, 2, 0 находок. Эти проверки не вызывают LLM.

## Общий веб-интерфейс

```bash
bash run.sh ui
```

Адрес: `http://127.0.0.1:8080`.
Запуск поднимает все зарегистрированные HTTP-стенды команды, поэтому требует
больше ресурсов, чем отдельные проверки NoSQLi.
Для воспроизводимой демонстрации выключить использование LLM в интерфейсе.

В PowerShell общий запуск: `./run.ps1 ui`.

Адреса стендов:

| Стенд | Локальный порт |
|---|---:|
| Juice Shop | 3000 |
| Demo Full | 3001 |
| DAN simulation | 3002 |
| Juice Shop NoSQLi | 3004 |
| MongoDB API | 3005 |
| SSRF simulation | 3006 |
| Security Key | 3007 |
| Второй MongoDB API | 3008 |

## Что проверено до передачи

Локальные тесты объединённого проекта и настоящий Semgrep:

- матрица NoSQL JS/TS и общий отчёт: 40 ожидаемых находок;
- исходники MongoDB API: 3 находки с согласованной категорией;
- SQLi, LFI, RFI: проверочные модули команды прошли;
- SQLi hardening: 6 точных находок;
- SAST-baseline наборов sample, sast-contours, DAN, SSRF, security key,
  spoofing совпали с ожиданиями;
- корректно отличены чистый исходник и сканирование без исходников;
- Compose проверен с профилями и совместимым тестовым overlay;
- проверены уникальность портов и команды выбора профилей Bash.

PowerShell-запуск не исполнялся в локальной Linux-среде без `pwsh`;
соответствующие тесты выполняются при наличии PowerShell.
Полные Docker-прогоны именно объединённой версии требуют проверки
на машине с Docker. Успех отдельных веток не заменяет эту проверку.
