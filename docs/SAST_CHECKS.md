# Проверка SAST-регрессий

Общий запуск объединяет проверки SQLi, LFI, RFI, кандидатов в секреты,
защиты от `nosemgrep` и контракта ответа Semgrep.

```powershell
docker compose build agent
docker compose --profile agent run --rm --no-deps --entrypoint python agent -m benchmark.verify_sast_regressions
```

Команда не поднимает HTTP-стенды, не вызывает LLM и не исполняет анализируемые
PHP/JavaScript/Python-примеры. Нужен образ со включённым Semgrep.

## Проверяемые наборы

| Проверка | Ожидаемый результат |
|---|---|
| `sast-contours` | 6 ожидаемых ID правил и все 12 исходников |
| `sast-sqli-hardening` | 6 находок по точным файлам, правилам и строкам |
| `sast-sqli-variants` | 14 находок, ноль на безопасных примерах |
| `sast-lfi-variants` | 14 находок, ноль на безопасных примерах |
| `sast-rfi-variants` | 14 находок, ноль на безопасных примерах |
| `sast-secrets` | 12 кандидатов; 8 контрольных файлов без находок |
| `scanner-contract` | чистый ввод принят, пустой скан отклонён, `nosemgrep` не скрывает SQLi/LFI/RFI |

Каждый набор использует реальный Semgrep и производственный SAST-парсер.
Результат означает обнаружение потенциального паттерна, а не доказательство
эксплуатации. Непустой список просканированных файлов также не доказывает полного
покрытия произвольного проекта.

Итог сохраняется в `logs/sast-regression/summary.json`, raw JSON каждого прогона —
в той же папке. Проверки продолжаются после отдельной ошибки, а итоговый статус
становится `failed`. Файл сводки обновляется атомарно.

См. также [контракт Semgrep](sast-output-contract.md) и
[кандидаты в секреты](SAST_SECRETS.md).
