# Проверка поиска OWASP Juice Shop

Учебная DAST-проверка локального приложения по адресу
http://localhost:3000.

## Запуск

Нужны Python 3.10+ и запущенный Juice Shop.
Дополнительные пакеты не требуются.

Из корня репозитория:

```bash
python3 dast_lab/check_search.py
```

## Что проверяется

| Параметр q | Результат при проверке |
|---|---|
| apple | HTTP 200, три товара |
| zzzz_no_such_product_762 | HTTP 200, пустой список |
| apple' | HTTP 500, ошибка SQLITE_ERROR |
| apple'' | HTTP 200, пустой список |

Скрипт обрабатывает HTTP-ошибки и сетевые ошибки отдельно.
Результаты сохраняются в search_report.json рядом со скриптом.
Каждый запуск перезаписывает отчёт.

## Вывод

Обнаружено раскрытие внутренней ошибки SQLite.
Различие ответов на одну и две кавычки указывает на возможную
SQL-инъекцию, но изменение логики SQL-запроса пока не подтверждено.

Это проверка одного известного endpoint, а не универсальный сканер.
Отрицательный результат не доказывает отсутствие уязвимости.

## Рекомендации

Использовать параметризованные SQL-запросы.
Не возвращать клиенту внутренние ошибки базы данных:
подробности сохранять в серверном журнале.

Статус completed означает, что получены все ответы и прошли
контрольные проверки. Он не означает отсутствие уязвимостей.

Статус inconclusive означает, что данных недостаточно для вывода.
Значение null в выводах означает неопределённость.
